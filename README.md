# Vefixa for Webmin

Webmin integration for Vefixa — server security monitoring,
scan results and agent management.

## Project status

In development. No installable release is available yet.

## Planned features

- Secure pairing with a Vefixa account.
- Security score, recent scans and findings.
- Agent detection and installation with administrator approval.
- Connection status, diagnostics and access revocation.
- Links to the full Vefixa dashboard.

The module will use the official Vefixa API.
Available features will depend on account permissions and plan.

## Installation

Installation packages and instructions will be published
in GitHub Releases after testing and release approval.
